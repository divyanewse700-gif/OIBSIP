# To-Do Web App

A simple and responsive To-Do Web App created for the Oasis Infobyte Web Development & Designing Internship.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Clear all completed tasks
- Press Enter to add a task
- Shows the number of remaining tasks
- Saves tasks using browser Local Storage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
