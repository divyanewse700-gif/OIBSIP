# Login Authentication System

A simple front-end login and registration system created for the Oasis Infobyte Web Development & Designing Internship.

## Features

- User registration
- Email and password validation
- Password confirmation
- Login validation
- Incorrect login error message
- Dashboard after successful login
- Welcome message with user's name
- Logout functionality
- Login state maintained using Local Storage
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Authentication Flow

```text
Register
   ↓
Account Saved
   ↓
Login
   ↓
Dashboard
   ↓
Logout
