# Calculator – OIBSIP Level 2 Task 1

## 📌 Project Description

A simple and responsive calculator web application built using HTML, CSS, and JavaScript.

The calculator performs basic arithmetic operations and supports both mouse and keyboard input.

## ✨ Features

* Addition, subtraction, multiplication, and division
* Decimal number support
* Clear button
* Backspace button
* Division-by-zero error handling
* Sequential operator chaining
* Keyboard support
* Responsive design
* CSS Grid button layout
* No `eval()` used

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

1. Download or clone the repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons or keyboard to perform calculations.

## 🧪 Example Operations

* `5 + 3 = 8`
* `10 - 4 = 6`
* `6 × 7 = 42`
* `20 ÷ 4 = 5`
* `2.5 + 2.5 = 5`
